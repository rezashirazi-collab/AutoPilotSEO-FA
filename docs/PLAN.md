# نقشهٔ ساخت سئو خودران

منبع: «سند طراحی محصول سئو خودران» (۲۲ اکتبر ۲۰۲۶). فازها همان نسخه‌های نقشهٔ راه سند هستند، شکسته به قطعه‌های قابل تحویل. اصل سند: اول مغز (تحلیل و اولویت‌بندی) با تأیید ناظر، بعد دست (نوشتن در سایت).

## معماری

- **AutopilotSeo.Core**: موجودیت‌ها، `AppDbContext` (EF Core 10 + SQL Server)، قواعد و الگوریتم‌ها. مستقل از زبان رابط؛ بعداً همین هسته از راه API به جت‌سئو سرویس می‌دهد.
- **AutopilotSeo.Web**: ASP.NET Core 10 Razor Pages؛ سایت معرفی، پنل کاربر، و (از فاز ۲) جاب‌های پس‌زمینه با `BackgroundService`.
- **AutopilotSeo.Tests**: xUnit برای قواعد و الگوریتم‌ها.
- دیتابیس: `AutopilotSeo` روی سرور dev (SQL Server 2019، compatibility level 150). رشتهٔ اتصال در user-secrets.
- قاعدهٔ سند: همهٔ نوشتن‌ها روی سایت فقط از یک «اجراکننده» می‌گذرد (عکس قبل ← بررسی کهنگی ← نوشتن ← بازخوانی ← ثبت در دفتر).

## فاز ۴ — موتور فرصت و صف ناظر (پایان نسخهٔ ۰٫۱)

- فرصت‌های نزدیک صفحهٔ اول، شکاف CTR با منحنی خود سایت، افت محتوا (با تشخیص نوع افت)، هم‌نوع‌خواری
- فرمول اولویت: `recoverable_clicks × value_per_click × confidence / effort` و بودجهٔ هفتگی
- کارت فرصت با شاهد داده؛ صف بازبینی ناظر با فرم امتیاز و کد دلیل؛ نقش‌های ناظر
- تغییر وضعیت پروژه با پیشنهاد سیستم و تأیید ناظر
- **شرط عبور سند:** ناظر ۷۰٪ فرصت‌ها را درست و اولویت‌بندی را منطقی بداند
