# سئو خودران

سئوکار نرم‌افزاری: به سرچ کنسول و وردپرس وصل می‌شود، هر هفته مهم‌ترین کار سئوی سایت را با شاهد داده پیشنهاد می‌دهد، بعد از تأیید اجرا می‌کند و اثرش را با گروه کنترل می‌سنجد.

- فناوری: .NET 10، ASP.NET Core Razor Pages، EF Core و SQL Server
